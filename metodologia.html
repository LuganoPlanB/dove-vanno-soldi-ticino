Metodo di estrazione

I dati del Preventivo 2027 sono stati estratti manualmente dal comunicato stampa del Consiglio di Stato. Il processo è documentato nel file data/ESTRAZIONE.md nel repository del progetto.

Dove necessario, sono stati effettuati calcoli semplici e trasparenti. Ad esempio:

  • Ricavi correnti 2027 = Spese correnti - Disavanzo = 4'318.2M - 98.5M = 4'219.7M CHF

Dati mancanti

Al momento della pubblicazione del sito (3 ottobre 2026), non sono ancora disponibili i seguenti dati:

  • Serie storiche: debito pubblico e disavanzi 2020-2026
  • Dettaglio per dipartimento: suddivisione delle spese per i 7 dipartimenti cantonali
  • Dettaglio per funzione: classificazione delle spese per settore (educazione, sanità, giustizia, ecc.)
  • Dati comunali aggregati: finanze dei comuni ticinesi

Questi dati sono disponibili nei documenti ufficiali (preventivi e consuntivi in formato PDF), ma richiedono un'estrazione manuale che non è ancora stata completata.

Se il Canton Ticino pubblicasse questi dati in formato aperto e strutturato (es. CSV o JSON su dati.ti.ch), sarebbe possibile integrare automaticamente le serie storiche complete.

Come verificare i dati

Ogni cittadino può verificare l'accuratezza dei dati visualizzati:

  1. Consultare il comunicato ufficiale
  2. Confrontare i numeri con quelli visualizzati sul sito
  3. Consultare i file JSON nella cartella data/ del repository GitHub
  4. Leggere il documento data/ESTRAZIONE.md che descrive passo per passo l'estrazione

Come contribuire

Questo è un progetto aperto. Puoi contribuire in diversi modi:

  • Estrarre dati storici: aiutarci a completare le serie storiche dai consuntivi PDF
  • Verificare i dati: segnalare eventuali errori o imprecisioni
  • Migliorare le visualizzazioni: proporre nuovi grafici o miglioramenti
  • Tradurre: aggiungere traduzioni in tedesco, francese o romancio

Il codice sorgente è disponibile su GitHub sotto licenza aperta. Leggi il README per le istruzioni su come contribuire.

Limitazioni e note

  • I dati del preventivo 2027 sono stime e potrebbero differire dal consuntivo finale
  • Il debito pubblico di fine 2027 è indicato come "superiore a 3 miliardi": utilizziamo 3'000M come valore di riferimento
  • Le percentuali sono arrotondate a una cifra decimale
  • Non vengono fatte proiezioni o stime: solo dati ufficiali pubblicati
  • Il sito è indipendente e non è affiliato al governo cantonale
